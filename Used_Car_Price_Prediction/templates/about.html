ABOUT THE PROJECT

Pricing, made understandable.

CarRcheck is an internship project demonstrating a complete, reproducible machine-learning workflow for used-car resale estimation.

The objective

Used-car prices depend on many interacting factors. This system turns those signals into an estimate while keeping the workflow explainable and easy to run locally.

Workflow

CSV data → validation and cleaning → exploratory analysis → preprocessing pipeline → model comparison → saved best model → Flask prediction form.

Algorithms compared

Linear Regression
Decision Tree Regressor
Random Forest Regressor

Technology

Python · Pandas · NumPy · scikit-learn · Joblib · Flask · HTML · CSS · JavaScript
